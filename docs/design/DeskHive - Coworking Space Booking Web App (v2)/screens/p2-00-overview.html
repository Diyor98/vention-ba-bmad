Three themes running in parallel

Theme A unlocks Themes B and C. Within each theme, screens ship as they're designed — the developer can pull stories off the top of the stack.

Theme A · Multi-tenant

Space Owners as a first-class role

Application + review + Owner dashboard. Two new logged-in modes (Guest / Hosting), one switch in the user menu.

Theme B · Payments

Stripe Checkout & Connect

Payment in the booking flow, payouts to hosts, 15% platform fee. Stripe owns the form — we own the entry & return.

Theme C · Email

13 transactional templates

One shared wrapper, one tone. Plain-text fallback per template. Sent via Resend with SPF + DKIM signing.
