Constraints honored

  • Disabled buttons read as obviously unclickable (muted bg, muted fg, no hover affordance, cursor: not-allowed).
  • Only semantic HTML — no custom dropdowns, modals, or popovers.
  • Subtle effects only — single hairline borders, --shadow-md max on card hover, no glass.
  • StatusBadge is a single component with four variants; large size used where the brief calls for dominance.
